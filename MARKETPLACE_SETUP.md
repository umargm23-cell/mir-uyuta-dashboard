# «Мир Уюта» v3.1 — категории Ozon и Wildberries

## Что работает

Панель умеет запрашивать **реальные категории через официальные Seller API**, но только после подключения API-доступов. Результаты — подсказки, выбранная категория применяется к полям открытой карточки и сохраняется только после нажатия **«Сохранить»**.

- **Ozon**: POST `https://api-seller.ozon.ru/v1/description-category/tree` — название, `description_category_id`, `type_id`.
- **Wildberries**: GET `https://content-api.wildberries.ru/content/v2/object/all` — родительская категория, предмет, `subjectID`.
- Изменение карточек Ozon/WB через API **не выполняется**. Только чтение категорий.
- Данные товаров и фотографии в Supabase не изменяются при поиске.
- Никаких SQL-миграций не требуется.

## Один раз: настройка секретов в Supabase

Открой [Supabase → проект mir-uyuta → Edge Functions → Secrets](https://supabase.com/dashboard/project/npecgcxncwmgbqgqregh/functions/secrets) и добавь:

| Имя секрета | Что указать |
|---|---|
| `OZON_CLIENT_ID` | Client ID из настроек Seller API в кабинете Ozon |
| `OZON_API_KEY` | Отдельный действующий API-ключ Ozon с минимальными правами чтения категорий |
| `WB_CONTENT_API_TOKEN` | Токен Wildberries с разрешением **Контент** (для чтения справочника предметов) |
| `MARKETPLACE_ALLOWED_USER_IDS` | Supabase Auth UID владельца магазина. UID найди в **Authentication → Users**. Несколько UID — через запятую. |

**Никогда не вставляй ключи в ChatGPT, GitHub, HTML-файлы или публичные сообщения.** Публикация проекта GitHub Pages открыта для чтения, поэтому секреты должны храниться только на стороне Supabase.

Функция `marketplace-categories` уже развёрнута. Для `[functions.marketplace-categories]` используется `verify_jwt=false` на шлюзе для современных publishable keys, **но пользовательская авторизация через `@supabase/server` с `auth:'user'` остаётся обязательной**, а `MARKETPLACE_ALLOWED_USER_IDS` дополнительно ограничивает доступ к API продавца. На все запросы действует лимит частоты.

## Как проверить

1. Открой [Мир Уюта](https://umargm23-cell.github.io/mir-uyuta-dashboard/v2.html) и войди.
2. Открой Alba → разверни **«Категории из Ozon и Wildberries»**.
3. Введи слово **стакан** и нажми **«Найти категории Ozon и WB»**.
4. Должны появиться реальные названия, ID категорий и типов. Выбери точный товар отдельно для Ozon и WB.
5. Убедись, что данные перенеслись в поля категории; нажми основное **«Сохранить»**.

Если один из API не настроен, появится понятное сообщение без подставных категорий. Проверь срок действия токена и права доступа, если видишь 401/403.

## Важные ограничения

- Сопоставление по названию — лишь **поиск кандидатов**, а не автоматическое назначение категории.
- Площадка может менять категории, атрибуты и правила публикации; проверяй назначение и комплектность.
- Для Ozon **обязательны два ID** — категории и типа товара. Для WB — **ID предмета**.
- Отметка «готово по чек-листу» означает полноту полей, не фактическую публикацию или юридическую корректность ОКПД2/ТН ВЭД.
