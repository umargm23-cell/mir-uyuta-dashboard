# Правила предварительного автоподбора ОКПД2 и ТН ВЭД (v2.5)

В карточке товара открой **«Подобрать ОКПД2 и ТН ВЭД»**. Модуль читает заполненные поля «Название» и «Материал», спрашивает недостающие характеристики для классификации стеклянных изделий и предлагает коды. Только после ручной проверки можно перенести выбранные значения в поля карточки; в Supabase они записываются лишь при сохранении самой карточки.

## Поддерживаемые товарные группы
- Сосуды для питья из хрусталя: ОКПД2 **23.13.12.110**, из прочего стекла: **23.13.12.120**.
- Столовая/кухонная посуда из хрусталя: **23.13.13.111**, из другого стекла: **23.13.13.112**.
- Стеклянные декоративные вазы: **23.13.13.141** / **23.13.13.142** — полный ТН ВЭД автоматически не утверждается.
- Посуда столовая/кухонная из фарфора: **23.41.11.110**; предварительно ТН ВЭД **6911100000**.

Для стекла ТН ВЭД зависит от ножки, содержания PbO ≥24%, упрочнения, способа изготовления, декора и в отдельных случаях коэффициента теплового расширения. Пока эти сведения неизвестны, показывается только группа ТН ВЭД (например, 7013) и **не предлагается неполный код для записи в карточку**. Названия «хрусталь» и «хрустальное стекло» не доказывают PbO ≥24%.

Не предусмотрено автоматическое присвоение кодов для стали, смешанных материалов, керамики без уточнения, сложных наборов или неоднозначных товаров. Нельзя утверждать точный код только по маркетинговому названию или названию коллекции.
